# 04 · LightGCN —— Simplifying and Powering GCN（SIGIR 2020）

## 一句话
**把 NGCF 里那两个零件（W 和 σ）删掉，只保留"邻居信息平均过来"这一步，结果反而更好。**

## 怎么跑
它不是 BPR 式训练，有自己的入口：
```bash
python papers/04_lightgcn_2020/model.py --epochs 300 --dim 64 --layers 3
```
约 45 分钟。结果写进 `results/metrics.tsv`。

## 结果

| 指标 | 我的数 | best epoch |
|---|---|---|
| HR@10 | **0.7149** | 220 |
| NDCG@10 | **0.4265** | 220 |

**比 NGCF（0.6879）高 2.6 个点，比纯点积 BPR-MF（0.6889）高 2.6 个点。**

## 我读出来的结论
1. **删掉 W 和 σ → 涨 2.6 个点**。这说明对协同过滤来说，真正有效的是"邻域聚合"，不是"特征变换"。
2. 270–300 轮的 HR 波动只有 0.0023 → 220 轮之后是**收敛**，不是过拟合。
3. 它仍然输给序列模型 SASRec（0.8295），差 11.5 个点 → 图能看"谁和谁相连"，看不了"先看什么后看什么"。

## 局限（方法本身的）
- 只用 ID 交互，冷启动失效
- 静态图，不做增量更新
- 过平滑：实际只能用 2–4 层
- 均匀负采样 → 假负例
- 推理要对全量物品算分
