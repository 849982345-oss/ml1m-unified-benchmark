# 02 · NCF —— Neural Collaborative Filtering（WWW 2017）

## 一句话
**把"算相似度"这件事交给神经网络去做**，赌它能学到点积学不到的东西。

三个结构：
- **GMF**：两个向量逐元素相乘（其实就是矩阵分解）
- **MLP**：两个向量拼起来过三层全连接
- **NeuMF**：把上面两个合起来（论文的主推模型）

## 怎么跑
```bash
cd C:\research-training\repro-ncf
python main.py --model NeuMF --epochs 50
```

## 结果

| 模型 | 我的 HR@10 | 我的 NDCG@10 | 论文报告 | 差 |
|---|---|---|---|---|
| GMF | 0.6396 | 0.3676 | 图读数 ≈0.645 | −0.005 |
| MLP | 0.6750 | 0.3978 | 图读数 ≈0.640 | +0.035 |
| **NeuMF** | **0.6904** | 0.4086 | **0.688 / 0.410** | +0.0024 / −0.0014 |

结果文件：`results/GMF_ml-1m_factor8.tsv`、`MLP_...tsv`、`NeuMF-end_...tsv`

## 我读出来的结论
**数字复现了（NeuMF 差 0.0024），但结论没复现。**
因为第 01 篇的 BPR-MF 用纯点积就拿到 0.6889 —— 和 NeuMF 的 0.6904 打平。
所以"神经网络学相似度更好"这个核心主张，在同等调参下不成立。

这个结论后来在 *NCF vs. MF Revisited*（RecSys 2020）里有系统证明，还指出 NCF 原文的指标是在测试集上挑最优 epoch 得到的。

## 局限（方法本身的）
- 参数量大、推理要对全量物品算分
- 只用 ID，冷启动失效
- 集合建模，忽略顺序
