# 01 · BPR-MF —— Bayesian Personalized Ranking（UAI 2009）

## 一句话
**不给用户打分，只判断"这两个电影你更喜欢哪个"。** 点积算相似度，用成对比较来训练。

## 为什么它排在第一
它是后面所有模型的**强基线**。如果一篇论文的模型打不过它，那这篇论文的价值就要打问号。
（2020 年有人专门复盘过：NCF 这类"神经网络推荐"其实没赢过它。）

## 怎么跑
```bash
cd C:\research-training\ml1m-unified-benchmark
python run.py --model bpr_mf --epochs 300
```

约 5 分钟。结果自动写进本文件夹 `results/metrics.tsv`。

## 结果

| 指标 | 我的数 | 说明 |
|---|---|---|
| HR@10 | **0.6889** | 推荐 10 个里有 68.89% 的用户被命中 |
| NDCG@10 | **0.4130** | 考虑排位，比 HR 严格 |
| best epoch | 50 | 第 50 轮最好，之后开始过拟合 |

### 怎么看 results/metrics.tsv

```
epoch   HR@10     NDCG@10
10      0.5xxx    0.3xxx
...
50      0.688907  0.412963   ← 最好的一行，报这个
...
300     0.678825  0.4088xx   ← 掉下来了，过拟合
```

**第一列是训练到第几轮。报数只报 HR 最大的那一行，两个指标都取这一行。**

## 我读出来的结论
1. **它和 NeuMF（0.6904）几乎打平**，而 NeuMF 的参数量多一个量级 → "复杂不等于更好"。
2. NDCG 上 BPR-MF 反而更高（0.4130 vs 0.4086）→ 它的排序质量更好，只是命中率略低。
3. 50 轮之后开始掉 → **正则不足**，这是下一步要调的第一个参数（`--reg`）。

## 局限（方法本身的）
- 只用 ID 交互，冷启动失效
- 静态，不建模时间
- 均匀负采样，大量"假负例"
