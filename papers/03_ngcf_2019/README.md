# 03 · NGCF —— Neural Graph Collaborative Filtering（SIGIR 2019）

## 一句话
**把用户和电影连成一张二部图，让信息沿着边传**，这样能利用"多跳"的隐含关系
（比如：你喜欢的 A 和 B 很像，而 B 又被和你相似的人喜欢）。

它的传播公式里保留了 GCN 从图像任务带过来的两个零件：
- **W**（特征变换矩阵）
- **σ**（非线性激活）

## 怎么跑
```bash
python run.py --model ngcf --epochs 300 --dim 64 --layers 3
```
约 35 分钟（3 层传播 + 两个 W 矩阵，比纯点积重）。结果写进 `results/metrics.tsv`。

## 结果

| 指标 | 我的数 | best epoch |
|---|---|---|
| HR@10 | **0.6879** | 140 |
| NDCG@10 | **0.4150** | 140 |

**注意：它比第 01 篇的纯点积 BPR-MF（0.6889）还低 0.001。**

## 我读出来的结论
给纯矩阵分解加上"图传播 + W + σ"这一整套，**HR 没有提升，反而略降**。

这直接引出第 04 篇：LightGCN 把这套 W 和 σ 删掉，只留传播，HR 涨到 0.7149。

三篇连起来看（BPR-MF → NGCF → LightGCN）就是一句：
> **收益不来自"更复杂"，来自"更对的归纳偏置"。**

## 局限（方法本身的）
- 特征变换和非线性是为"节点带语义特征"的图设计的，协同过滤的节点只有 ID，这两步没有可变换的输入
- 参数量比 MF 大，训练更慢
- 层数一深就过平滑
