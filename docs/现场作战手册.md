## 环节 3 · 看结果：现场演示「怎么读一个实验结果」（4 分钟）

**做什么**：打开 `lightgcn_ml-1m_run1.tsv`，让他随便指一个 epoch。

**你说这四句**（这是教会他"你会看结果"的最快方式）：

> 我看一个实验的结果，固定看四件事：
>
> **第一，趋势对不对。** HR 是不是整体在涨。如果一开始就 0.8，那是数据泄漏，不是好结果。
>
> **第二，什么时候达峰。** 这个模型 220 轮达峰。如果最后一轮还在猛涨，说明训练不够，我报的这个数就偏低了。
>
> **第三，达峰后回不回落。** 这里 270 到 300 波动 0.0023，不到千分之三 —— 是收敛。如果明显往下掉，那是过拟合，得早停或者加正则。
>
> **第四，HR 和 NDCG 是不是同步。** 如果 HR 涨但 NDCG 不动，说明"蒙进前 10"变多了，但排序质量没提高，这种情况要警惕。

**追问预备**：
- 「你为什么取 220 轮不取 300 轮？」→「取 best-HR 那一行，这是通行做法；300 轮的数字更低，报它反而对我不利，但 220 才代表模型能达到的水平。」
- 「那你是不是在挑好的报？」→「我报的是同一行的 HR 和 NDCG，不是各自取最优。三个种子也是全部报均值，不是挑最好的那个。」

## 环节 4 · 调参对话（5 分钟，这是最容易被考的地方）

导师问「超参对结果有什么影响」时，**别背公式，用"两条线"的框架**：

> 调参本质上是在欠拟合和过拟合之间找平衡，判断靠看两条线：训练 loss 和验证指标。
>
> **两条都还高** → 欠拟合，加 epoch、加维度、或者 lr 太小学不动。
> **loss 还在降但验证指标不涨甚至回落** → 过拟合，加 dropout、加正则、或者减容量。

然后按参数逐个一句话（敏感度从高到低）：

| 参数 | 一句话 |
|---|---|
| **学习率** | 最关键。太大震荡发散，太小几十轮还没收敛。我用 1e-3。 |
| **epoch** | 超过平台期就是白跑。我的 LightGCN 220 轮达峰，跑到 300 已经没意义。 |
| **batch** | 大一点梯度稳但泛化略差，小一点噪声大、还慢。 |
| **维度** | 大表达强、易过拟合；小表达不足。图模型 64 够，序列 50 够。 |
| **层数 / block 数** | 图深了过平滑，实际只能 2–4 层；SASRec 论文明确说 2 层最好，加到 4 层退化。 |
| **正则 / dropout** | 大了欠拟合，小了过拟合。序列 0.2，图基本不用。 |
| **负采样比例** | 少了学不到"不喜欢"，多了慢且容易过拟合热门负样本。 |

**收口必须说这句**（这是加分点）：

> 论文做了超参网格搜索，我只固定了一组——**这本身就是我和论文数字有差距的原因之一**。但我判断在这份数据上继续调，边际收益已经小于"换个数据集验证结论成不成立"的收益了。
