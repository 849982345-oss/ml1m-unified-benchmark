# 推荐系统论文复现 · MovieLens-1M

**六篇论文，一个文件夹一篇。每篇里面有：模型代码 + 复现说明 + 我跑出来的结果。**

所有模型跑在**同一份数据、同一套评分规则**上，所以六个数可以横向比。

## 结果总表

协议：MovieLens-1M · leave-one-out（每用户最新一条为测试）· 100 候选（1 正 + 99 负）· HR@10 / NDCG@10 · 6,040 用户均值

| # | 论文 | 建模假设 | HR@10 | NDCG@10 | 论文报告 |
|---|---|---|---|---|---|
| 01 | **BPR-MF** | 集合 · 纯点积（强基线） | **0.6889** | **0.4130** | — |
| 02 | NCF-GMF | 集合 · 点积 | 0.6396 | 0.3676 | 图读数 ≈0.645 |
| 02 | NCF-MLP | 集合 · 非线性 | 0.6750 | 0.3978 | 图读数 ≈0.640 |
| 02 | NCF-NeuMF | 集合 · 融合 | 0.6904 | 0.4086 | **0.688 / 0.410** |
| 03 | NGCF | 图 · 传播 + W + σ | 0.6879 | 0.4150 | 该协议未报告 |
| 04 | LightGCN | 图 · 纯邻域传播 | 0.7149 | 0.4265 | 该协议未报告 |
| 05 | **SASRec** | **序列 · 自注意力** | **0.8295 ± 0.0014** | **0.5976 ± 0.0007** | **0.8235 / 0.5958** |
| 06 | BERT4Rec | 序列 · 双向 + 完形填空 | 0.7785 | 0.5669 | — |

![八个模型对比](figures/bars_all.png)

---

## 三条结论

**① 序列 ≫ 图 > 集合。** SASRec（0.8295）比 NeuMF（0.6904）高 13.9 个点 HR。不是调参能补的。

**② BPR-MF 与 NeuMF 打平（0.6889 vs 0.6904，NDCG 上 BPR-MF 还高 0.0044）。**
→ 复现出了 NCF 的数字，**但没复现出它的结论**。

**③ 删掉 W 和 σ 反而更好。** NGCF（0.6879，带 W 和 σ）< LightGCN（0.7149，删掉 W 和 σ）。
→ 收益不来自"更复杂"，来自"更对的归纳偏置"。

## 怎么跑（一篇一篇跑）

```bash
# 01 BPR-MF（约 5 分钟）
python run.py --model bpr_mf --epochs 300

# 03 NGCF（约 35 分钟）
python run.py --model ngcf --epochs 300 --dim 64 --layers 3

# 06 BERT4Rec（约 2 分钟）
python run.py --model bert4rec --epochs 200

# 04 LightGCN（有自己的入口，约 45 分钟）
python papers/04_lightgcn_2020/model.py --epochs 300

# 02 NCF 和 05 SASRec 在各自 README 里写了原始仓库的跑法
```

**结果会自动写进那篇论文自己的 `papers/XX_xxx/results/metrics.tsv`。**

跑完汇总：

```bash
python common/report.py     # 重出总表 + figures/bars_all.png
```

## 为什么还有一个 `common/`

| 文件 | 作用 |
|---|---|
| `common/data.py` | 加载 ML-1M 官方切分，断言每个用户恰好 100 个候选 |
| `common/eval.py` | **唯一的评分实现**：HR@10 / NDCG@10 |
| `common/report.py` | 扫六篇的结果，出总表和对比图 |

**六篇论文共用这一套评分，所以六个数能比。** 模型文件里不允许自己写评估——这是保证协议不被偷偷改掉的硬约束。

---

## 数据

- 切分：NCF 官方 leave-one-out 产物（994,169 训练 + 6,040 测试）
- 候选：官方 `test.negative`，每用户 1 正 + 99 负
- 规模：6,040 用户 / 3,706 物品 / 1,000,209 交互

`data/build_ml1m_seq.py` 负责从这份切分重建序列数据，并做一致性校验（剔除长尾后行数与官方 SASRec 预处理版精确相等）。
